## 📌 Sobre o Projeto

Este projeto consiste em uma **Estrutura Modular de Rotas Multi-Páginas** com um formulário interativo no estilo **Typeform / Google Forms** que **gera automaticamente o PDF do Prontuário/Ficha do Paciente (com o TCLE)** para a Dra. Laura salvar na pasta de prontuários do computador dela ou no Google Drive!

---

## 📄 Geração Automática de PDF do Prontuário (Novo!) 📄

Ao finalizar o preenchimento da ficha em `anamnese.html`:
1. **Geração Instantânea de PDF**: O site compila automaticamente um documento oficial `Ficha_Anamnese_[Nome_do_Paciente].pdf` formatado com o timbrado da Dra. Laura Detoni Queiroz, CRP 12/13874, data/hora do registro e o aceite assinado digitalmente do TCLE.
2. **Download Automático**: O arquivo `.pdf` é baixado direto para o dispositivo.
3. **Notificação no WhatsApp**: O resumo formatado é enviado para o WhatsApp do consultório informando que a ficha física/PDF foi gerada!
